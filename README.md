武林江湖模拟系统 README
```
📖 项目简介
本项目基于 Java 实现12×12 武林江湖对战模拟系统，模拟少林、武当、峨眉三大门派弟子的移动规则与对战机制。系统按照 战斗 → 移动 的循环逻辑，迭代 N 步后统计各门派存活弟子数量与总生命力，完整还原题目设定的武林厮杀规则。
🎮 核心规则
1. 场景坐标
固定 12 行 12 列的方形武林地图，坐标范围：(1,1) ~ (12,12)。
2. 各门派移动规则
- 少林(S)：固定列纵向往返移动，先向下触底后向上循环
- 武当(W)：固定行横向往返移动，先向右触底后向左循环
- 峨眉(E)：右下-左上对角线往返移动；(1,12)、(12,1) 点位永久静止
每一步所有存活弟子同步移动一格，不可滞留、不可多走/少走。
3. 对战触发规则
仅满足以下条件触发战斗，其余场景无战斗：
- 同一格子内，仅有两个不同门派弟子相遇
- 同门弟子相遇、三派弟子同框、单人独处，均不触发战斗
- 单次相遇仅战斗一次，战斗结束后生命力 ≤0 的弟子直接淘汰消失
4. 攻击力计算公式（浮点运算后向下取整）
核心属性：内力、武艺、生命力（取值范围：0~100）
- 少林攻击力 = (0.5*内力 + 0.5*武艺) * (生命力 + 10) / 100
- 武当攻击力 = (0.8*内力 + 0.2*武艺) * (生命力 + 10) / 100
- 峨眉攻击力 = (0.2*内力 + 0.8*武艺) * (生命力 + 10) / 100
战后生命力 = 战前生命力 - 对方攻击力
5. 迭代逻辑（单步流程）
单次步数严格遵循顺序：全员结算战斗（淘汰阵亡弟子） → 存活弟子同步移动，循环迭代至指定步数 N（N < 1000）。
📥 输入说明
1. 首行输入测试用例组数
2. 每组用例首行输入迭代步数 N
3. 后续多行输入弟子信息，格式：门派代号 行号 列号 内力 武艺 生命力
4. 以单独一行 0 作为单组用例结束标志
门派代号：S少林、W武当、E峨眉
📤 输出说明
每组用例输出 4 行结果：
1. 第一行：少林派 存活弟子数 总生命力
2. 第二行：武当派 存活弟子数 总生命力
3. 第三行：峨眉派 存活弟子数 总生命力
4. 第四行：固定分隔符 ***
📝 示例输入输出
输入示例
```
2
1
S 1 2 20 20 20
W 2 1 20 20 20
0
2
S 1 2 20 20 20
W 2 1 20 20 20
E 12 12 20 20 100
0
输出示例
1 20
1 20
0 0
***
1 14
1 14
1 100
***
```
✨ 项目特性
- 严格遵循题目迭代逻辑，战斗、移动流程精准无误
- 精准的浮点运算取整规则，完全匹配攻击力计算标准
- 自动筛选有效战斗场景，过滤无效对战情况
- 自动淘汰阵亡弟子，最终精准统计门派数据
```
